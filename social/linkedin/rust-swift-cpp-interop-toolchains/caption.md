# Three pages on Rust and Swift meeting C++

## Body
Three pages from September 2026 describe how Rust and Swift toolchains deal with C++. I read each primary page on 10 October.

Microsoft's guest post on the Rust Foundation site says Rust is a Tier-1 language at Microsoft. That is an internal support label, not a Rust compiler target tier. It describes rustc_codegen_utc, a backend that connects rustc to the MSVC code generator, with more than 100 Microsoft repositories building with it.

The Rust Foundation's interop update says Google funds the work, 40 interop problems are tracked, and a draft matrix compares rustc, Crubit, cxx and Zngur. The Swift 6.4 release post says Swift bridges C++20 std::span with Span.

The Swift post names no compiler flags. I did not read the Crubit, cxx or Zngur projects, Microsoft's internal plans or the Swift compiler documentation beyond two pages.
