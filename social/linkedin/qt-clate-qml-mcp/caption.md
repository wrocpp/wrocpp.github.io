# Qt's Clate turns a no-code UX design into QML, and ships an MCP server

## Body
The Qt Company released Clate, a beta design tool for embedded and HMI interfaces. A designer works without code and Clate writes QML in the background, so the handoff to a developer is working QML rather than a mock-up.

It also has a built-in MCP server, so an agent from any MCP-capable application can connect to it. The assistant inside Clate runs on Claude at launch, with more models announced.

The page is plain about what is not there yet. QML is the only output. Component libraries, data bindings and variables are listed for 2026, and design tokens, motion and collaboration for Spring 2027. It lists no microcontroller target.

Przemyslaw Nogaj flagged the release. The facts in the post are from the product page.
