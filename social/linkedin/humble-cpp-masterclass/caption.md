# Humble Bundle sells 21 Packt C++ ebooks for EUR 16.35 until 12 October

## Body
Humble Bundle is running a Packt C++ book bundle: 21 ebooks, DRM-free in PDF and EPUB, until 12 October at 18:00 UTC (20:00 in Warsaw).

There are three tiers. EUR 4.53 gets three books, EUR 13.62 gets seven, and EUR 16.35 gets all 21. The gap between the last two is EUR 2.73 for fourteen more books. You choose how the money splits between Packt, The Global FoodBanking Network and a Humble tip.

The titles I would open first: Fedor Pikus on design patterns, Marius Bancila on template metaprogramming and his Modern C++ Programming Cookbook, Patrice Roy and Michael Wong on memory management, Modern CMake for C++, Sourav Ghosh on low latency, and LLVM Code Generation by Quentin Colombet and Kristof Beyls.

Some limits to know before buying. Where a description names a standard it is C++20 or C++23, with C++26 mentioned only by the C++ STL Cookbook. Learn LLVM 17 is six major releases behind LLVM 23. One book is about C and one about Rust. The post has the full tier table.

Packt's community team told us about the bundle. We are not paid for this and the link carries no affiliate code.
