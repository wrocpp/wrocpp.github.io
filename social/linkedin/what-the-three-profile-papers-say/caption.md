# What Bjarne Stroustrup's three October profile papers say

## Body
Bjarne Stroustrup's three October papers on profiles are P3704R1, P4222R3 and P4418R0. The first says what a profile is and is not. The other two give concrete designs: one requires every object to be initialized before use, the other rejects access through dangling pointers.

The post summarises each paper from its PDF and shows how a profile is switched on and off, using the attributes from P3589R3. It also lists where the papers disagree with each other or with the implementation report P4415R0. One example: P3704R1 and P4418R0 show a Clang build that rejects the invalidation example, P4415R0 says Clang has no invalidation profile, and none of the Clang builds on Compiler Explorer that I tried rejects it.

The post takes no side.
