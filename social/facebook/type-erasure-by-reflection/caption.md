# Reflection writes the type-erasure table, and C++26 still makes you write the member names

## Body
Episode 4 of the series on pimpl and type erasure in C++26. Reflection reads a plain interface struct and builds the type-erasure table with define_aggregate, with the same 32-byte result as the hand-written version. C++26 cannot inject member functions, so the names come back with one forwarding line per member.
