# Four official Qt examples build and run without moc

## Body
Four examples from Qt 6.10.3 were rewritten by a migration tool and built with AUTOMOC off. Each prints the same output as the moc build, and a build where moc is replaced by a failing trap passes.

The diffs are 14 to 111 changed lines. The post lists the limits of the check, and the library is public at https://github.com/wrocpp/reflect-moc

https://wrocpp.github.io/posts/qt-four-examples-without-moc/
