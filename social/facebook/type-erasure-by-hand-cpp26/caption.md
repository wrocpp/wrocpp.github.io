# Sean Parent's type erasure by hand in C++26, with a 24-byte buffer and deducing this

## Body
Episode 3 of the series on pimpl and type erasure in C++26. A drawable value holds any shape with draw, area and scale, copies like a value, and asks for no base class. On GCC 16.2 it is 32 bytes and keeps small shapes in a 24-byte buffer. The design is Sean Parent's; the post writes it by hand with deducing this.
