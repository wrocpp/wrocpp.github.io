# Qt's Clate turns a no-code UX design into QML, and ships an MCP server

## Body
The Qt Company released Clate, a beta design tool for embedded and HMI interfaces. A designer works without code, and Clate writes QML in the background, so the handoff is working code, not a mock-up. It has a built-in MCP server for agents, and the assistant inside runs on Claude at launch.

QML is the only output so far, and most of the roadmap is dated 2026 and 2027.
