# Boost 1.91 adds the decimal type C++ does not have

## Body
Adding 0.1 to a double a thousand times gives 99.999999999998593. The same loop with Boost.Decimal's decimal32_t gives exactly 100, and the demo runs live on Compiler Explorer with Boost 1.91.
