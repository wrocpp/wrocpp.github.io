# 228 of 2,613 tracked C++ projects now ship a module

## Body
A tracker of C++20 module adoption has reached 228 projects. It recorded 62 last November, so it is moving quickly.

It follows 2,613 projects in total, which puts adoption at 8.7 percent.

A tick there means the module exists, not that it is switched on. Of three well-known libraries, two keep the module behind a build option that defaults to off, and nlohmann/json still describes its module as experimental.

The one module underneath all of them is import std. In a single file it builds on GCC 16 and on neither Clang nor MSVC, which both expect the build system to compile the std module first.

Measured on Compiler Explorer, not quoted from documentation.
