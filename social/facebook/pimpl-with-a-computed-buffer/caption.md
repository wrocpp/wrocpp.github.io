# A pimpl with an inline buffer, and three ways to get its size right

## Body
Episode 1 of a series on pimpl and type erasure in C++26. A pimpl that keeps its Impl in a buffer inside the object saves one allocation per object and per copy, but its header must state a size it cannot see. The post checks the number with a C++26 static_assert message, then lets reflection generate it. The same Impl is 72 bytes with libstdc++ and 56 with libc++.
