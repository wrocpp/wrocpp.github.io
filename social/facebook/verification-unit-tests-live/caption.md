# A real GoogleTest suite runs in your browser

## Body
New series: building a C++ verification setup one layer at a time. This is the bottom layer, the one everybody already has.

GoogleTest is a Compiler Explorer library. Add it, turn on the execution pane, and a real test binary builds and runs in the browser with the familiar RUN and OK report.

The useful part is that it is a URL. When someone claims a function behaves a certain way, you settle it with a link anyone can fork, instead of asking them to install a toolchain first.
