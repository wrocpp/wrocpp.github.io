# Twelve Qt security advisories between 2 and 16 November, two rated high

## Body
Qt published twelve security advisories between 2 and 16 November 2026. Two are rated high: a memory corruption in the FFmpeg backend (CVSS 3.1 8.8) and an XML reader that can exhaust memory (CVSS 4.0 8.2). On 17 November the open-source directory had Qt 6.11.3 but no 6.12.1, and nothing newer than 6.8.5 for 6.8. The post lists all twelve with affected and fixed versions.
