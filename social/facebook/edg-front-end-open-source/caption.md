# EDG's C++ front end is open source

## Body
On 30 September the source of the EDG C++ front end went public under the LLVM licence, with the C++ Alliance as its nonprofit sponsor. GCC, clang and EDG are now all C++ front ends you can read.

Compiler Explorer added EDG builds with C++26 reflection the same day. I ran one snippet that lists a struct's members on GCC 16.2, EDG 7.0, EDG trunk and clang-p2996. All four run it, and the output differs in one type spelling. EDG rejects template for, so the snippet uses an index_sequence.

One snippet says nothing about how complete EDG's reflection is, and the roadmap is not published yet.
