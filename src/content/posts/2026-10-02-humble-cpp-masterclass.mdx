Humble Bundle is running a Packt book bundle called [C++ Programming Masterclass: Code Faster. Build Smarter. Master C++](https://www.humblebundle.com/books/c-programming-masterclass-code-faster-build-smarter-master-c-books). It holds 21 ebooks, DRM-free, in PDF and EPUB. The minimum is €4.53 for three of them, and €16.35 unlocks all 21. You choose how the payment splits between Packt, The Global FoodBanking Network, and a tip to Humble. The bundle ends on 12 October 2026 at 18:00 UTC, which is 20:00 in Warsaw.

## Where I would start

- Hands-On Design Patterns with C++, by Fedor Pikus, in its second edition. It treats patterns as C++ techniques: type erasure, CRTP, policy-based design.
- Marius Bancila's two books. Template Metaprogramming with C++ covers C++20 concepts and constraints. The Modern C++ Programming Cookbook is the third edition and has recipes for `std::expected`, `std::mdspan`, and synchronized output streams.
- C++ Memory Management, by Patrice Roy and Michael Wong, both long-standing WG21 members. It covers ownership, smart pointers, and writing your own allocators.
- Modern CMake for C++ (second edition) and CMake Best Practices, if you maintain a build.
- Building Low Latency Applications with C++, by Sourav Ghosh, which builds the parts of an electronic trading system from scratch, with performance data for each.
- Debunking C++ Myths, which takes common claims about the language one at a time and checks them.
- LLVM Code Generation, by Quentin Colombet and Kristof Beyls, both long-time LLVM backend developers. It goes from LLVM IR down to assembly.

## What to know before buying

Among the descriptions that name a standard, Template Metaprogramming with C++ and Software Architecture with C++ are built around C++20, and the Modern C++ Programming Cookbook reaches C++23. The C++ STL Cookbook is the only one whose description mentions C++26.

Learn LLVM 17 is written against a release from 2023. LLVM is at 23 now and its C++ API changes between major versions, so expect some of the book's code to need edits. Bare-Metal Embedded C Programming is a C book for Arm microcontrollers, and Rust for C++ Developers is a Rust book.
