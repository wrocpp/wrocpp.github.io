# Beyond main.cpp: Building a Maintainable C++ Project

An external event, shared at the organisers' request. Wro.cpp does not run it.

Nikolai Kutiavin, author of *No More Helloworlds: Build a Real C++ App*, takes a single-file calculator and grows it into a structured project with separate components, a CMake build and unit tests. The event page says attendees get the source code for each stage.

The webinar is online and free, presented by Deep Engineering and hosted by Packt Publishing. It runs on 20 January 2027 from 14:00 to 15:30 UTC. Registration is on [Luma](https://luma.com/oetzs5y4).
